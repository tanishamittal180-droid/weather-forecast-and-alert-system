# 🌦️ Weather Forecast & Alert Application
## 📌 Project Overview
The **Weather Forecast & Alert Application** is a Python-based system that provides **real-time weather updates, forecast analysis, and automated alerts** for any city worldwide.
It uses public weather APIs to fetch live data, processes it, and presents insights through an interactive dashboard built with Streamlit.
## 🎯 Problem Statement
People often check weather manually and may miss important conditions like:
* Heavy rain 🌧️
* Heat waves 🔥
* High humidity 💧
This project solves that by:
* Fetching weather data automatically
* Analyzing conditions
* Generating alerts
* Displaying everything visually
## 🚀 Features
### 🌍 Global City Support
* Enter any city (no restriction)
* Automatic geolocation using API
### 🌦️ Real-Time Weather Data
* Temperature
* Humidity
* Rain probability
### 🚨 Smart Alert System
* 🔥 High Temperature Alert
* 💧 High Humidity Alert
* 🌧️ Rain Alert
### 📅 Forecast Analysis
* 7-day weather forecast
* Trend visualization
### 🗺️ Interactive Map
* Displays location using Folium

### 📊 Data Visualization
* Line charts for trends
* Forecast charts
### 🔄 Auto Refresh
* Updates every 2 minutes
### 📥 Report Generation
* Download weather report as CSV
## 🛠️ Tech Stack

| Category      | Tools Used            |
| ------------- | --------------------- |
| Language      | Python                |
| API           | Open-Meteo API        |
| Frontend      | Streamlit             |
| Data Handling | Pandas                |
| Visualization | Streamlit Charts      |
| Maps          | Folium                |
| Auto Refresh  | streamlit-autorefresh |
## 🌐 How It Works
1. User enters city
2. App fetches weather data using API
3. JSON response is processed
4. Weather conditions analyzed
5. Alerts generated
6. Dashboard displays data
